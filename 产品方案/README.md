# 店脑 AI · 六方案整合与微信 ClawBot 接入包

日期：2026-11-07｜版本 V2.0｜实施状态：方案/原型代码，**未经真实 ClawBot 主机部署联调**

## 目录

1. `01-店脑统一产品方案_V2.md`：完整的综合 PRD、功能保留清单、冲突取舍、路线图、测试。
2. `02-微信ClawBot接入手册.md`：腾讯微信插件安装、架构、双 Agent、安全绑定、调试。
3. `03-业务接口_OpenAPI.yaml`：10 个示范业务接口；这是**店脑自建 API**，非微信官方 API。
4. `04-核心数据库草案.sql`：PostgreSQL 领域骨架；**不是可直接上线的完整生产迁移**，缺少多表 RLS/应用权限细化。
5. `05-反诈官方案例来源_待审核.md`：检索到的公安部门案例来源，需平台审批后入库。
6. `config/行业配置样例.json`：母婴、服装、汽修、医美、药店 5 个行业模板 + 公共反诈独立配置。
7. `skill/SKILL.md` 与 `skill/ask.py`：OpenClaw 低复杂度内部测试说明与只读 API 调用脚本。
8. `plugin/`：基于 OpenClaw SDK 的只读业务 Tool 原型，内建微信 sender ID 白名单，适合单店员工小范围验真。

## 优先执行顺序

先按主方案建立 200 客户、80 SKU 的模拟数据和母婴 V1 最小数据库/网页；在真实 OpenClaw 主机安装腾讯插件并扫码，先验私聊 → 再部署店脑后端 API → 最后安装业务 Tool、验证授权和证据引用。未经授权不允许将 ClawBot 发布成可读取商家私有资料的公开聊天入口。

所有 token 与数据库连接串需在目标环境的机密配置注入，**不要提交到代码仓库**。不要把名为 `example.invalid` 的占位域名误认为正式服务。
