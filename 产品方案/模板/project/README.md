# 店脑：门店经验与老客服务系统

店脑帮助门店保存客户购买历史与员工经验，让新店员查到正确资料，继续为老客户服务。

**当前状态：开发前的使用说明模板，产品尚未完成上线验收。以下描述的是计划提供的操作流程，试用地址和已支持能力以正式发布时的更新为准。**

## 谁来使用

- 店主／管理员：管理店员、导入资料、审核经验、按权限导出。
- 店员：查询授权客户资料，查看历史与经验，补充本次服务记录。

首发以母婴店为试点。客户与孩子分别管理，同一客户可关联多个孩子。

## 首次使用

1. 管理员开通门店空间并登录，邀请店员账号。
2. 按导入模板准备客户、商品与历史记录；首版计划支持CSV，其他格式按正式版本说明处理。
3. 上传文件并检查字段映射及预览，确认正确后导入；错误行修改后重新提交。
4. 整理老员工经验，检查适用场景、建议步骤和注意事项，审核后让店员查询。

正式试用地址：待发布。账号开通方式、支持联系人、导入模板下载位置：由试点负责人上线前填写。

## 一次接待怎样完成

1. 在客户搜索中输入会员号、姓名或手机尾号。
2. 出现多个候选时补充线索，确认客户和本次服务的孩子。
3. 查看客户卡片中的历史购买、已审核经验和待确认信息；点开来源核对记录时间。
4. 服务结束后填写本次商品或服务记录，检查后确认提交。

系统默认以简短三行提示呈现重点；详细信息在客户卡片查看。没有记录时会明确说明，不会自行补造客户历史。

## 怎样留下员工经验

输入经验→检查提取草稿→提交审核→管理员批准→进入正式检索。过时或错误经验由管理员修订或下架，历史修改保留记录。

客户实际发生的事实与一般经验分别展示。发现资料冲突时先核对来源，再补充更正，不直接把AI建议作为已发生事实。

## 导出与员工交接

管理员按授权范围导出，操作保留记录。店员默认无批量导出权限。员工离职后管理员撤销其访问权限，已保存的客户资料和经验继续留在门店。

## 微信和防诈功能

微信文本查询及身份绑定计划作为独立能力验证，通过后补充开通步骤与支持范围；未验证前请使用网页。

防诈演示采用单独审核的公开案例，不读取门店客户档案；只显示可核对的依据与不确定项。案例没有命中不代表安全。该演示尚未启用。

## 常见情况

| 情况 | 操作 |
|---|---|
| 手机尾号找到多个人 | 补充会员号、姓名等线索，确认后再打开档案 |
| 查不到上次购买 | 核对客户与服务对象是否正确，检查历史记录是否已导入 |
| AI回答缺资料或有冲突 | 点开来源核对时间，补充资料或交管理员处理 |
| 导入部分失败 | 查看错误行与原因，修正后再提交 |
| 微信不可用 | 使用网页完成查询与记录，向试点负责人反馈 |
